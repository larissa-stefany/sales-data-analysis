# Dicionário de Dados

| Coluna | Descrição |
|---|---|
| pedido_id | Identificador do pedido |
| data | Data da venda |
| produto | Produto vendido |
| categoria | Categoria do produto |
| quantidade | Quantidade de itens |
| preco_unitario | Preço unitário do item |
| cidade | Cidade da venda |
| estado | UF da venda |
| forma_pagamento | Meio de pagamento utilizado |
| cliente_id | Identificador sintético do cliente |
| faturamento | Quantidade × preço unitário, calculado no tratamento |

Os dados são sintéticos e destinados exclusivamente a estudo e portfólio.
