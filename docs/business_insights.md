# Insights de Negócio Esperados

Este projeto foi estruturado para responder perguntas simples e comuns em uma análise comercial.

## Indicadores principais

- Faturamento total
- Número de pedidos
- Quantidade de itens vendidos
- Ticket médio

## Recortes de análise

- Receita por categoria e produto
- Evolução mensal das vendas
- Cidades com maior faturamento
- Formas de pagamento mais utilizadas
- Clientes com maior receita acumulada

## Como interpretar

O objetivo não é apenas calcular métricas, mas transformar os resultados em prioridades de negócio. Categorias com grande participação no faturamento merecem acompanhamento próximo, enquanto cidades e produtos com desempenho abaixo da média podem indicar oportunidades de ação comercial.

Como a base é sintética, os resultados servem para demonstrar raciocínio analítico e domínio do fluxo Python + SQL, e não para representar uma empresa real.
